Like Mint, but open source and on your computer

A budgeting app for your spending, bills, and net worth. Link your banks with your own Plaid keys, and tally keeps it all in one file on your machine.

Read the install guide jclind/tally

MIT licensed. Mac or Linux. US banks.

Setup

# Mac or Linux, with Node 24 and git
git clone https://github.com/jclind/tally.git
cd tally
# add the keys from your free Plaid account
npm start
# open localhost:3400
