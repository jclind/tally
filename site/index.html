A money app that runs on your own computer

tally shows your spending, budgets, bills, and net worth, using your own Plaid keys. Everything stays in a SQLite file on your computer, and there's no tally account.

Read the install guide

Free and open source.
Mac or Linux, with US or Canadian banks.

What tally shows

What you need

A Mac or Linux computer
It can sleep. tally catches up when you open it.
Node 24 or newer, and git
tally has no npm dependencies.
A free Plaid account
The Trial plan covers 10 bank connections for life.
Tailscale, if you want it on your phone
tally has no login, so it stays off the internet.
git clone https://github.com/jclind/tally.git
cd tally
# add your Plaid keys, see the guide
npm start
tally on http://localhost:3400 (keys found)
