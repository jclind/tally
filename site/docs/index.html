Before you start

  • A Mac or Linux computer. Windows may work under WSL2, but nobody has tested it.
  • Node 24 or newer, and git. Check Node with node -v. Get it from nodejs.org or, on a Mac, brew install node.
  • A US bank. tally only links US banks for now.

1Get Plaid keys

  1. Create a Plaid account and verify your email.
  2. Apply for the free Trial plan. Plaid offers it to teams created on or after April 15, 2026. For an older team, check the plans on your dashboard.
  3. Go to Developers → Keys. Copy your client_id and your Sandbox secret. You'll use the Production secret in step 4.
Don't apply for full Production access. Plaid ends the free Trial once you submit a Production application, and you can't go back.

2Install tally

There's no npm install step.

git clone https://github.com/jclind/tally.git
cd tally

Add your keys

Swap in your client_id and Sandbox secret, then run this. It writes ~/.config/tally/plaid.env, readable only by you.

mkdir -p ~/.config/tally
cat > ~/.config/tally/plaid.env <<'EOF'
PLAID_CLIENT_ID=your-client-id
PLAID_SECRET=your-sandbox-secret
PLAID_ENV=sandbox
EOF
chmod 600 ~/.config/tally/plaid.env

Start and check it

npm start
Expected output
tally on http://localhost:3400 (keys found)

If it says (keys missing), see keys missing. Otherwise open localhost:3400.

3Link an account

Open Accounts and choose Link a bank or card, or Link a brokerage for investments.

In sandbox, pick any bank and sign in with the test login user_good and password pass_good. tally loads test accounts and transactions.

4Switch to your real banks

Stop tally (Ctrl+C) and set the sandbox data aside:

mv data data-sandbox

Edit the keys file so it holds your Production secret:

PLAID_CLIENT_ID=your-client-id
PLAID_SECRET=your-production-secret
PLAID_ENV=production

Start tally again with npm start. In Settings, Your setup should now say production.

Then link your banks from Accounts the same way.

The free Trial plan allows 10 connections in total. Removing one doesn't give the slot back, and tally stops at 10 unless you raise the limit in Settings for a paid plan. If a bank stops syncing, use Fix connection on the Accounts page instead of linking it again.

Keep it running

On a Mac

Stop tally (Ctrl+C) first. One script then starts it at login, restarts it if it stops, and runs the daily sync at 7:00, or when the Mac wakes if it was asleep then:

bin/install-mac.sh

The log is tally.log in the tally folder. For another sync time or port, add --at 06:30 or --port 3500.

On Linux

Run node server.mjs under systemd or another process manager, and schedule node bin/daily.mjs for the morning with cron or a timer.

Backups and updates

Copy data/tally-snapshot.db and the ~/.config/tally/ folder somewhere else, encrypted, on a schedule. tally writes the snapshot after every full sync, and it's safe to copy while tally runs.

The snapshot holds your Plaid access tokens. Without it you'd link every bank again.

Update tally

On a Mac, from your tally folder, pull the new code and restart tally:

git pull
launchctl kickstart -k gui/$(id -u)/local.tally

On Linux, run git pull and restart the service you set up.

Use it on your phoneOptional

tally has no login, so it only listens on your computer. Tailscale lets your phone reach it over your tailnet without exposing it to the internet.

  1. Install Tailscale on the computer and your phone, and sign in to both with the same account.
  2. In Tailscale's admin console, under DNS, turn on MagicDNS and HTTPS certificates.
  3. On the computer, serve tally over HTTPS: 
    tailscale serve --bg 3400
    If port 443 is already in use on this computer, add --https=8400 before 3400, and put :8400 after the address in the next step.
  4. Tell tally its new address. tailscale serve status prints the full address. On a Mac: 
    bin/install-mac.sh --host your-computer.your-tailnet.ts.net
    On Linux, add this environment variable to the service you set up, then restart it: 
    TALLY_HOSTS=your-computer.your-tailnet.ts.net

Open https://your-computer.your-tailnet.ts.net on your phone and add it to your home screen.

Other ways in

From another computer, an ssh tunnel needs nothing set up in tally. Run this there, then open localhost:3400:

ssh -L 3400:127.0.0.1:3400 your-computer

A reverse proxy with its own login, like Caddy with a password or Cloudflare Tunnel with Access, also works. Add its address to TALLY_HOSTS, and have it pass the original Host header. That puts tally on the internet behind the proxy's login, so only do it if you trust that setup.

Never use Tailscale Funnel or a port forward for tally. Either one puts your accounts on the public internet with no password.

Discord alertsOptional

The daily job can post to a Discord channel when a charge reaches your alert amount ($200 unless you change it in Settings), a budget goes over, or a bank stops syncing (weekly until it's fixed).

  1. In Discord, open a channel's settings, then Integrations → Webhooks, and copy a webhook URL.
  2. In tally, open Settings, turn on Post alerts to Discord, and paste the URL.

Using tally

Budgets
On Budgets, type a monthly amount next to any category. With no budgets yet, Fill them in sets every category from your last three months. The tick on each bar is today, so a bar past its tick is spending ahead of the month.
Fix a category
On Activity, click a transaction's category and pick another. Tick Every … transaction to apply it to that merchant from now on.
Search
Search names, amounts, or categories. mcdonalds finds McDonald's, 6.75 finds that exact charge, and groc finds Groceries.
Look back
The month name at the top of Home, Spending, and Budgets is a menu. Pick a past month to see all of it.
When it syncs
tally syncs when you open it or switch back to its tab, if the data is more than 12 hours old. Sync when you open tally in Settings changes that.

Troubleshooting

The log says "keys missing"

tally reads ~/.config/tally/plaid.env. Check that the file exists and has both PLAID_CLIENT_ID and PLAID_SECRET.

A bank shows an error on the Accounts page

Its sign-in expired or changed. Click Fix connection and sign in again.

A bank won't connect

Some large banks sign you in on their own site (OAuth). Check Plaid's dashboard for an OAuth institutions page; a few banks need you to request access there first. Link from the computer's own browser, not from your phone.

A bank has only a few months of history

That's what the bank gives Plaid. Some send two years, some about 90 days.

The page won't load on my phone

Run tailscale serve status on the computer, and make sure the address you passed to --host matches it, with :8400 only if you served on 8400. tally.log names any address tally refused.

Something else

Open an issue on GitHub with the lines from tally.log. Leave out anything with your account details.
